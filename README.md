# Schema Studio

DBML 텍스트로 테이블과 관계를 편집하는 개인용 웹 ERD 도구입니다.

## 실행

Node.js 22 이상에서 실행합니다.

```sh
npm install
npm run dev
```

http://127.0.0.1:3001 에서 사용합니다. `npm run build`로 배포 빌드를 검증하고 `npm start`로 실행할 수 있습니다. Vercel에서는 Next.js 프로젝트로 가져오면 됩니다.

## 현재 기능

- DBML 편집과 컬럼 단위 관계선, PK·설명 표시
- 테이블 드래그, 화면 확대·축소, 미니맵, ELK 자동 배치
- 테이블 헤더 색상과 그룹 테이블 일괄 색상 변경 (DBML 원문에 반영)
- 관계선 선택과 색상 변경 (프로젝트 JSON에 저장)
- 문법 오류 시 마지막 정상 관계도 유지
- DBML 가져오기·내보내기, 원문과 배치를 포함한 프로젝트 JSON 가져오기·내보내기
- 브라우저 localStorage 자동 저장 (현재 문서 1개)
- 이전 대화에 첨부한 율촌 Board DBML 예제

테이블·컬럼에 마우스를 올리면 설명 전체를 볼 수 있습니다. 관계는 DBML의 `Ref`로 작성합니다. 그룹 색상 버튼은 소속 테이블의 헤더 색상을 바꿉니다. 그룹 배경 박스, 이미지 내보내기, 마우스 연결 생성은 아직 구현하지 않았습니다.

DBML만 내보내면 배치와 UI에서 바꾼 관계선 색상은 포함되지 않습니다. 작업 전체는 **프로젝트 내보내기**로 보관하세요. 브라우저 저장소를 삭제하거나 다른 브라우저로 이동할 때에도 프로젝트 파일이 필요합니다.

## 다음 단계

Supabase Auth와 사용자별 프로젝트 목록·클라우드 저장은 후속 단계입니다. 현재 앱은 Supabase 환경 변수 없이 로컬에서 동작합니다. `supabase/migrations`의 RLS 포함 문서 테이블을 클라우드 저장의 기반으로 사용할 수 있습니다. 실제 DB 연결이나 SQL 실행 기능은 없습니다.

첨부된 율촌 예제는 `public/yulchon-board.dbml`에 포함되어 있습니다. 공개 배포 전 해당 업무 문서를 포함할지 검토하세요.
