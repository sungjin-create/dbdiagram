# Schema Studio

Next.js 기반 개인용 DBML ERD 편집기입니다. 텍스트 편집, 관계선, 다중 선택, 정렬 가이드, 파스텔 색상, 자동 배치, 색상별 정렬, 프로젝트·폴더 관리를 지원합니다.

## 실행과 배포

Node.js 22 이상에서 `npm install` 후 `npm run dev`로 실행합니다. 주소: http://127.0.0.1:3001

`.env.example`을 참고해 `.env.local`에 Supabase URL과 Publishable key를 설정하세요. 환경 변수가 없으면 브라우저 저장 모드로 동작합니다. Secret key 또는 service-role key는 사용하지 않습니다.

Vercel에는 같은 두 변수를 Settings → Environment Variables에 등록하고 다시 배포하세요. 환경 변수는 빌드할 때 반영됩니다.

## Supabase 설정

SQL Editor에서 아래 파일을 순서대로 한 번씩 실행합니다.

1. `supabase/migrations/202611060001_diagrams.sql` — 이미 실행했다면 건너뜁니다.
2. `supabase/migrations/202611060002_cloud_library.sql` — 폴더·사용자별 저장·충돌 방지 함수 추가.
3. `supabase/migrations/202611060003_security.sql` — 로그인 계정 변경 중 잘못된 저장 차단, 쓰기 권한 및 입력 제한 강화.

Authentication에서 Email 로그인을 사용합니다. 이메일 확인을 켠 경우 가입 메일의 링크를 누른 뒤 로그인하세요. Authentication → URL Configuration에서 Site URL을 실제 Vercel 배포 주소로 지정하고 Redirect URLs에 아래 주소를 등록합니다.

- `http://127.0.0.1:3001`
- 실제 Vercel 배포 주소 (`https://프로젝트.vercel.app`)

이메일 확인과 비밀번호 재설정이 이 주소로 돌아옵니다.

## 저장

- 비로그인: 기존 브라우저 저장소에 프로젝트·폴더·임시 문서를 보관합니다.
- 로그인: 사용자별 클라우드 저장을 사용합니다. 저장 버튼으로 프로젝트를 만든 후 수정한 원문·배치·색상은 자동 저장됩니다. 저장 전 임시 문서는 계정별 브라우저 캐시에 보관됩니다.
- 로그인 후 프로젝트 목록의 **브라우저 프로젝트 가져오기**는 기존 로컬 프로젝트와 임시 문서를 계정에 복사합니다. 기존 로컬 데이터는 유지되며, 브라우저·계정별 한 번만 실행할 수 있습니다.
- 연결 실패 시 계정별 캐시에 보관합니다. 저장 재시도로 동기화합니다. 서버 저장 상태는 하단과 프로젝트 목록에 표시합니다.
- 다른 창에서 먼저 저장한 경우 충돌을 표시하고 덮어쓰지 않습니다. 현재 프로젝트 또는 프로젝트 목록을 내보낸 후 **최신 목록**으로 갱신하세요.
- 로그아웃하면 비로그인 작업 공간으로 돌아갑니다. 계정별 캐시는 다른 계정 작업 공간에 자동으로 가져오지 않습니다.

DBML 내보내기는 원문만 포함합니다. 배치·관계선 색상까지 보관하려면 프로젝트 JSON을 내보내세요. 프로젝트 목록 백업은 모든 프로젝트·폴더를 포함하며, 가져오기에서 다시 불러올 수 있습니다.

클라우드는 `diagrams`, `diagram_folders`에 문서를 저장합니다. ERD 안의 테이블을 실제 DB에 생성하거나 SQL을 실행하지 않습니다. RLS와 트랜잭션 함수의 사용자 소유자 확인을 사용합니다. 여러 기기 저장 충돌은 목록 revision으로 감지하며 자동 병합하지 않습니다.

업무 예제는 `private-examples/`에 로컬 보관하며 Git과 공개 배포에서 제외합니다. 이전 Git 커밋에 포함했던 파일은 과거 기록에 남아 있을 수 있습니다.

`npm test`로 파서·오류 위치·문서 전환·가져오기 검증·로컬 PostgreSQL 권한/저장 회귀 테스트를 실행합니다. `npm run typecheck`, `npm run build`로 타입과 배포 빌드를 확인합니다. 로컬 DB 테스트는 PGlite를 사용하며 실제 Supabase 데이터에는 접근하지 않습니다.

편집기에서 오류에는 빨간 밑줄과 줄 번호 옆 표시가 나타납니다. 표시 위에 마우스를 올리면 오류 설명을 볼 수 있습니다. 문법 오류가 있는 동안 마지막 정상 관계도를 유지합니다.
